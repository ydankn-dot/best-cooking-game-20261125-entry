Sizzle & Serve — run the Ember Lane Kitchen for one 2½-minute shift. Take ingredients from the crates, chop them on the board, grill the patty, plate the dish on the plating counter, and serve it at the window before the order's patience runs out. Four dishes, growing order pressure, a rush hour, combos and tips for fast serves. A complete offline cooking game in plain HTML/CSS/canvas JavaScript — no build step, no network, no libraries.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with WASD or arrow keys to move, E or Space to interact, or click a station to walk there and use it. P pauses, R restarts after a shift ends.
